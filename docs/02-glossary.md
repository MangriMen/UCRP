# 02. Глоссарий

Единые названия: русское имя — имя в коде (Go-тип / таблица БД / JSON-поле snake_case). Во всех документах использовать именно их.

## 1. Роли

| ID  | Роль               | Имя в коде (`role`) | Суть                                                                        |
| --- | ------------------ | ------------------- | --------------------------------------------------------------------------- |
| R-1 | Маркетолог УК      | `marketer`          | Основной пользователь: сегменты, рекомендации, выгрузки, лимиты, кампании   |
| R-2 | Управляющий ТЦ     | `manager`           | Заказчик: сводные показатели, журналы, пользователи                         |
| R-3 | Арендатор          | `tenant`            | Видит только свои агрегаты; привязан к одному Tenant (`app_user.tenant_id`) |
| R-4 | Аналитик данных УК | `analyst`           | Загрузка, отклонённые строки, склейки, справочники, качество источников     |
| R-5 | Посетитель / Гость | —                   | Не пользователь UI; объект данных (E-1) и получатель рассылки               |
| R-6 | Система / Сервис   | `system`            | Воркеры импорта, пересчёта, коннекторы API; действует через очередь         |

## 2. Сущности

| ID   | Русское имя                         | Код (Go / таблица)                                                 | Определение                                                                                           |
| ---- | ----------------------------------- | ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| E-1  | Гость                               | `Guest` / `guest`                                                  | Один человек, собранный из записей разных арендаторов; поддерживает soft-delete и состояние `merged`  |
| E-2  | Событие                             | `Event` / `event`                                                  | Визит, покупка или бронь: арендатор, проект, дата, сумма, источник; `raw_payload` — исходные атрибуты |
| E-3  | Сегмент                             | `Segment` / `segment` (+`segment_version`, `segment_member`)       | Версионируемое правило отбора гостей + материализованный список                                       |
| E-4  | Арендатор                           | `Tenant` / `tenant`                                                | Независимый бизнес в ТЦ; категория, этаж, координаты, приоритет продвижения                           |
| E-5  | Источник данных                     | `DataSource` / `data_source` (+`data_source_type`)                 | Конкретный канал данных арендатора (экземпляр CRM/POS/API/CSV) и его тип-справочник                   |
| E-6  | Категория арендатора                | `TenantCategory` / `tenant_category` (+`tenant_category_relation`) | Справочник категорий; связи «смежная» и «прямой конкурент»                                            |
| E-7  | Проект                              | `Project` / `project`                                              | Объект данных или направление бизнеса арендатора (допущение A-3)                                      |
| E-8  | Кампания                            | `Campaign` / `campaign`                                            | Маркетинговая цель: целевой арендатор, сегмент, окно атрибуции                                        |
| E-9  | Тип события                         | `EventType` / `event_type`                                         | Справочник: `visit`, `purchase`, `booking`; расширяется записью                                       |
| E-10 | Идентификатор гостя                 | `GuestIdentifier` / `guest_identifier`                             | Телефон / email / номер карты (нормализованные) + источник                                            |
| E-11 | Кандидат на склейку                 | `MergeCandidate` / `merge_candidate`                               | Пара профилей с причиной совпадения и решением; журнал склеек (в т.ч. автоматических)                 |
| E-12 | Запрет склейки                      | `UnmergeBlock` / `unmerge_block`                                   | Пара, которую нельзя склеивать автоматически после разъединения/отклонения                            |
| E-13 | Загрузка                            | `ImportBatch` / `import_batch`                                     | Одна загрузка файла или одно подтягивание из API; счётчики строк                                      |
| E-14 | Отклонённая строка                  | `RejectedRow` / `rejected_row`                                     | Строка загрузки с номером, кодом и текстом причины                                                    |
| E-15 | Рекомендация                        | `Recommendation` / `recommendation` (+`recommendation_factor`)     | До 3 мест для гостя, оценка и обоснование по факторам                                                 |
| E-16 | Выгрузка                            | `Export` / `export_job`                                            | Журнал выгрузки сегмента в канал; счётчики                                                            |
| E-17 | Член выгрузки                       | `ExportMember` / `export_member`                                   | Гость в выгрузке: получатель или контрольная группа                                                   |
| E-18 | Лимит контактов                     | `ContactLimit` / `contact_limit`                                   | Правило «не более N контактов за P дней» (по каналу или общее)                                        |
| E-19 | Контакт                             | `ContactLog` / `contact_log`                                       | Факт контакта гостя в рамках выгрузки (для лимита и конверсии)                                        |
| E-20 | Пользователь                        | `User` / `app_user`                                                | Учётная запись R-1…R-4                                                                                |
| E-21 | Аудит                               | `AuditLog` / `audit_log`                                           | Неизменяемый журнал значимых действий                                                                 |
| T-1  | Задание очереди (служебное, не E-*) | `Job` / `job_queue`                                                | Персистентная очередь воркеров; обоснование — D-8                                                     |

## 3. Термины

| Термин                             | Код                                | Определение                                                                                                                                                                                                            |
| ---------------------------------- | ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Единый профиль                     | `GuestProfile` (DTO)               | Гость + идентификаторы + лента событий + число посещённых арендаторов + рекомендации                                                                                                                                   |
| Лента событий                      | `GET /guests/{id}/events`          | Упорядоченный по `occurred_at` список Event гостя                                                                                                                                                                      |
| Нормализация                       | `identity.Normalize`               | Приведение ключей: телефон → E.164 (`79001234567`), email → нижний регистр, карта → цифры/буквы без разделителей                                                                                                       |
| Надёжный ключ                      | `KeyType`                          | Телефон, email, номер карты — допускают автосклейку                                                                                                                                                                    |
| Склейка (merge)                    | `MergeCandidate.resolution`        | Объединение двух Guest в один: события и идентификаторы переходят к победителю, проигравший получает `status=merged`, `merged_into_id`                                                                                 |
| Автосклейка                        | `auto_merged`                      | Склейка по надёжному ключу без конфликтующих признаков                                                                                                                                                                 |
| Спорная склейка                    | `pending`                          | Совпадение ключа при признаках конфликта (разные имена при общем телефоне и т.п.) либо слабое совпадение; ждёт решения R-4                                                                                             |
| Разъединение (unmerge/revert)      | `revert`                           | Возврат событий и идентификаторов к `origin_guest_id`; создаёт запрет (E-12)                                                                                                                                           |
| Запрет склейки                     | `UnmergeBlock`                     | Пара профилей, исключённая из автосклейки                                                                                                                                                                              |
| Match rate                         | метрика                            | Доля событий с `guest_id IS NOT NULL` среди всех принятых событий (цель ≥ 70%)                                                                                                                                         |
| Доля оспоренных склеек             | метрика                            | Число `merge_candidate` с `resolution=reverted` / число выполненных слияний (`auto_merged` + `confirmed` + `reverted`) за период (цель < 1%); отклонённые пары очереди (`rejected`) — не склейки и в метрику не входят |
| Cross-tenant penetration           | метрика                            | Доля активных гостей с событиями минимум у двух разных арендаторов; в распределении — 1 / 2 / 3+ арендатора. Вторичная метрика после «первой покупки у нового арендатора» (A-17)                                       |
| Сегмент                            | `Segment`                          | Правило на бизнес-языке («был / не был», арендаторы, период, наличие контакта) + список гостей                                                                                                                         |
| Версия правила                     | `segment_version`                  | Неизменяемый снимок правила; правка создаёт новую версию                                                                                                                                                               |
| Шаблон сегмента                    | `segment.is_template`              | Предустановленное правило: «Спящий сосед», «Один магазин», «Риск ухода», «Новичок», «Высокая ценность»                                                                                                                 |
| Скоринг рекомендаций               | `recommend.Scorer`                 | Взвешенная сумма факторов: похожие гости, смежность категорий, этаж/расстояние, свежесть, приоритет арендатора; прямой конкурент получает понижающий коэффициент (A-18)                                                |
| Понижение конкурента               | `factor_code = competitor_penalty` | Множитель для кандидата-конкурента категории, где гость уже бывает; по умолчанию < 1, настраивается; жёсткое исключение — опция категории (D-34)                                                                       |
| Fallback-рекомендация              | `recommend.Fallback`               | Выдача для гостя без истории: популярные арендаторы среди похожей аудитории и приоритет арендатора, с пометкой «мало данных» (A-21)                                                                                    |
| Контрольная группа                 | `export_member.is_control`         | Опциональная доля гостей сегмента, которых намеренно не включают в рассылку для измерения инкремента; процент настраивается, 0 — группа не выделяется (A-19)                                                           |
| Инкремент                          | метрика                            | Разница доли визитов в новое место между получателями и контрольной группой за окно атрибуции; вычисляется только при непустой контрольной группе                                                                      |
| Конверсия                          | метрика                            | Доля получателей, совершивших целевое действие у целевого арендатора в течение окна атрибуции (`campaign.attribution_days`, по умолчанию 14 дней)                                                                      |
| Окно атрибуции                     | `campaign.attribution_days`        | Настраиваемый период после контакта, в котором засчитывается целевое действие (A-6)                                                                                                                                    |
| Первая покупка у нового арендатора | метрика (главная)                  | Первое событие типа «покупка» у арендатора, где у гостя ранее не было событий; главная метрика успеха пилота (A-17)                                                                                                    |
| Пополнение / списание / визит      | `event_type.code`                  | Различаются как отдельные типы: `top_up` и `usage` не считаются посещением (`counts_as_presence=false`), визит — считается (A-20)                                                                                      |
| Реверс события                     | `event_type.code = reversal`       | Отмена или возврат, корректирующая исходное событие (A-20)                                                                                                                                                             |
| Уверенность в склейке              | `merge_candidate.score`            | Оценка 0…100; показывается пользователю при подтверждении спорных пар (A-5)                                                                                                                                            |
| Лимит контактов                    | `ContactLimit`                     | Ограничение частоты; при превышении выгрузка исключает гостей, а если исключены все — 409                                                                                                                              |
| Идемпотентность                    | —                                  | Повторная загрузка того же файла и повторный запрос с тем же `Idempotency-Key` не создают дублей                                                                                                                       |
| Ключ идемпотентности события       | `event.uq`                         | `(data_source_id, event_type_id, external_id)`                                                                                                                                                                         |
| Агрегаты арендатора                | `TenantAggregates`                 | Обезличенные счётчики по одному арендатору; единственные данные, доступные R-3                                                                                                                                         |
| Изоляция арендатора                | —                                  | Проверка `tenant_id` из claims на уровне service + обязательный фильтр в repository; запрещён доступ R-3 к данным других арендаторов                                                                                   |
| Очередь                            | `job_queue`                        | Персистентные задания воркеров с `dedup_key`, повторами и блокировкой                                                                                                                                                  |
| Идентификатор запроса              | `request_id`                       | Сквозной ID в логах, ответах об ошибках и аудите                                                                                                                                                                       |
| Внешний партнёр                    | `tenant.kind = 'external'`         | Арендатор вне комплекса (термы, SPA); архитектурная возможность, в MVP не включается (A-22)                                                                                                                            |
