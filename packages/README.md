# packages/

Общие пакеты, используемые **двумя и более** приложениями.

| Пакет            | Назначение                                                                   |
| ---------------- | ---------------------------------------------------------------------------- |
| `api-types/`     | Типы запросов и ответов API, синхронизированные с контрактами в `docs/`      |
| `tsconfig/`      | Базовые `tsconfig` для приложений                                            |
| `eslint-config/` | Общий конфиг линтера                                                         |
| `api-docs/`      | Инструмент: собранный `openapi.yaml` и локальный Swagger UI (`bun run docs`) |

Пакет попадает сюда только при наличии второго потребителя. Иначе код живёт внутри приложения. Исключение — `api-docs/`: инструмент разработки без потребителей среди приложений.
